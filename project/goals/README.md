# Project Goal Workspaces
> **Required for every goal:** maintain `ROADMAP.md`, `README.md`, and `ACTIONS.md`. Read the roadmap before work and update all relevant documentation in the same session. See [mandatory documentation rules](../DOCUMENTATION_RULES.md).

Each major SHIT objective has its own folder containing its scope, design decisions, current state, actions taken, verification evidence, and next steps.

## Cross-project status

**Current repository-wide priority: documentation completion only.** All 12 non-documentation goal workspaces separate a documentation-only next action from the preserved next feature action. Do not treat a future feature action as permission to resume implementation while the Maintainability & Documentation acceptance criteria remain open. See [the current handoff](../NEXT_WORK.md) and [the documentation roadmap](maintainability-documentation/ROADMAP.md).

See [LOOSE_ENDS.md](../LOOSE_ENDS.md) for unresolved work and verification blockers across all goal areas. The detailed history belongs in each goal's `ACTIONS.md`.

## How to use

1. Start at [the project handoff](../NEXT_WORK.md).
2. Read the relevant goal folder's `README.md` for scope, constraints, status, and resume instructions.
3. Read that folder's `ACTIONS.md` for chronological work, tests, decisions, and evidence.
4. Update both files after meaningful work; update the central handoff when priorities or blockers change.
